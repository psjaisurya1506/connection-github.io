# EEC Alumni Connect — Frontend Foundation

This version implements **Phase 1 (Frontend Foundation)** from the project roadmap:
- Professional responsive landing page
- Reusable Button, Navbar and Sidebar components
- DashboardLayout
- Student, Alumni and Admin dashboard UI previews
- Login and registration UI
- Responsive mobile layout
- Centralized design tokens and global styling

### Important
The supplied project did **not** contain Tailwind CSS in its installed dependencies. To keep this ZIP immediately runnable without changing the existing dependency set, Phase 1 uses a centralized CSS design system with Tailwind-style utility conventions. Tailwind can be introduced as the next setup step without changing the UI structure.

### Run
From `client`:

```powershell
npm run dev
```

The authentication forms and dashboard numbers are UI previews only at this stage. Backend/API integration is intentionally left for Phase 2, following the supplied roadmap.
